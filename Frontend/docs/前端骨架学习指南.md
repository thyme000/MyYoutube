# MyYoutube Vue 学习指南（新手版）

这份骨架目标是：**先用 Vue3 把页面结构跑起来**，后续你可以平滑接入 Spring 单体后端接口。

## 1. 当前目录结构

```text
MyYoutube/
├─ index.html                 # Vite 入口模板
├─ package.json               # npm 脚本与依赖
├─ .env.example               # API 地址示例
├─ vite.config.js             # Vite 配置
├─ src/
│  ├─ App.vue                 # 主页面骨架与交互
│  ├─ api/
│  │  ├─ http.js              # 统一请求封装
│  │  └─ videoApi.js          # 视频相关接口
│  ├─ main.js                 # Vue 挂载入口
│  └─ styles/
│     └─ main.css             # 全局样式
└─ docs/
   └─ 前端骨架学习指南.md
```

## 3. 如何运行

```bash
npm install
npm run dev
```

默认会输出一个本地地址（例如 `http://localhost:5173`），在浏览器打开即可。

## 4. 如何扩展（重点）

### 4.1 新增左侧菜单

在 `src/App.vue` 中找到：

- `primaryMenus`：主导航数组
- `exploreMenus`：探索数组

新增一个对象即可，例如：

```js
{ key: "sports", label: "体育", icon: "⚽" }
```

页面会自动渲染，不需要再手写 DOM。

### 4.2 接口层预留（已完成）

当前已完成接口分层：

1. `src/api/http.js`：统一封装 `fetch`、错误处理、query 参数。
2. `src/api/videoApi.js`：按业务封装 `fetchVideosByModule`、`searchVideos`。
3. `src/App.vue`：只负责页面交互，接口失败会自动回退本地演示数据。

这就是前后端分离常见写法：**组件不直接拼接口细节，后续维护更轻松**。

## 5. 与 Spring 单体后端对接建议

推荐先提供以下 API：

- `GET /api/videos/home`：首页推荐
- `GET /api/videos/shorts`：短视频
- `GET /api/videos/history`：历史
- `GET /api/videos/liked`：点赞
- `GET /api/videos/watch-later`：稍后再看
- `GET /api/search?keyword=xxx`：搜索

你可以直接按本项目的封装对接，Spring Boot 返回结构推荐：

```json
{
  "list": [
    {
      "id": 1,
      "title": "演示视频",
      "author": "官方频道",
      "viewsText": "3.2万次观看"
    }
  ]
}
```

如果你返回的是数组或 `records` 字段也可以，前端已做兼容。

## 6. 开发环境配置（重要）

你有两种方式连接 Spring Boot：

1. 使用 Vite 代理（默认已配置）  
   当前 `vite.config.js` 已把 `/api` 代理到 `http://localhost:8080`。

2. 使用环境变量基地址  
   复制 `.env.example` 为 `.env.local`，按需修改：

```js
VITE_API_BASE_URL=http://localhost:8080
```
